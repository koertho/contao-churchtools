# Calendar V2 implementation contract

Approved in conversation: native tl_calendar_events, optional one-to-one ChurchTools calendar assignment on tl_calendar; series templates as tl_content parents. No automatic migration or old data deletion. Contao 5.7 and 6, PHP 8.4.

## Shared interfaces
- Root namespace Koertho\ContaoChurchTools; calendar domain Calendar\Sync and Calendar\Frontend; callbacks in root EventListener/DataContainer/<Table>, cron root EventListener/Cron, Active Record classes root Model.
- tl_calendar: ct_calendar_id nullable unsigned integer UNIQUE, ct_last_sync nullable integer, ct_sync_error nullable text, ct_sync_counts nullable text (allowlisted JSON counters). Empty assignment is null. ct_calendar_id doNotCopy.
- tl_calendar_events: ct_sync_key nullable string(64), UNIQUE(pid,ct_sync_key); ct_calendar_id nullable unsigned integer; ct_appointment_id nullable unsigned integer; ct_series_template_id nullable unsigned integer; ct_hash nullable string(64); ct_last_sync nullable unsigned integer; ct_unpublished_by_sync string(1) default empty; ct_description nullable text. Every ct_* field doNotCopy. ct_sync_key = sha256(byte-exact calculated iCalUid). Native source=default, recurring empty.
- tl_ct_series_templates: id,tstamp,ct_appointment_id unsigned integer UNIQUE,title string(255),teaser text nullable, native full image fields. Model CtSeriesTemplatesModel registered TL_MODELS. No ptable on series; ctable tl_content, closed true.
- Sync service Calendar\Sync\CalendarEventSynchronizer::synchronize(?int $archiveId=null, ?DateTimeImmutable $now=null): array keyed by archive ID with status/error/counts. Uses existing SnapshotFetcher rewritten under Calendar\Sync, returning fields including repeatId, location/address from confirmed API fields. Preserve existing source validation; no raw metadata.
- Series relation: recurring current data assign template by base ID; known UID detached (repeatId=0) keeps old relation. Brand new standalone no guessed relation.
- Resolver Calendar\Frontend\EventContentResolver::resolve(array $event): array returns event with effective teaser/image fields, hasTeaser, details and hasDetails closures. Usable for hook and Twig reader. Native rendering of individual then series content. descriptions literal plaintext fallback after event and series teaser.
- Template contao/templates/event_full_churchtools.html.twig, Twig function churchtools_event resolving native template context by event ID. Native manual event context unchanged.
- Backend series module ct_series under content. Native calendar permissions for events; series module permissions for templates + dynamic tl_content parent including nested content. Protect imported writes, delete/copy/move incl direct actions.
- Existing church_tools config defaults past_months=1 future_months=6. CLI koertho:churchtools:calendar:sync with --archive. Cron */15 * * * *. Retain optional setup command and credentials config.
- Existing API/Transport and SnapshotFetcher completeness gates retained. API empty calendar not deletion authority. Archive transactions, MariaDB advisory locks; after-commit targeted CacheTagManager invalidation only changed data. No changes outside active time window; explicit deselection/reassignment unpublishes old source records in active window without deleting content.
- User publication override survives even unchanged hash; sync-unpublished reappearing records reactivate independently of hash. Manual toggle clears sync-unpublished flag.
- Old custom archives, entries, linking actions, two custom frontend elements and no-store listener removed from code, not automatically from DB.

## Integration rulings / actual implementation
- EventContentResolver and Twig extension share list and reader behavior. Native 5.7 list reloads event image metadata, so full inherited image settings require the selectable event_list_churchtools template as well as event_full_churchtools for the reader.
- Native own-reader figures preserve module size; inherited reader uses series size, optional churchtools_event(_context, imageSize) explicitly overrides. No global model mutation or parseTemplate hook.
- Backend source POSTs hold the same archive advisory lock as sync until request finish; orphan series deletion locks its row through successful response commit, with exception rollback. Series manager also locks detached retained template references.
- Native Versions restore excludes ct_* universally and source fields only on imported events. Successful actual publication changes clear the sync marker; teaser-only and invalid saves do not.
- Native content copy/cut callbacks invalidate old/new ultimate series tags; normal nested-content edits append parent series tags. Sync also invalidates the reader-root sitemap tag.
- Test schema comparator checks extension-modified tables only, avoiding core MariaDB JSON alias drift on tl_content.jsonData. No new tl_content columns.
